# Super Shoes

Projeto Front-End desenvolvido com React e TypeScript simulando uma loja virtual de calçados.

O projeto foi utilizado para praticar conceitos de componentização, consumo de APIs, manipulação de estado e desenvolvimento de interfaces modernas. A implementação inicial do carousel foi baseada em material de estudo, enquanto as evoluções posteriores, correções e melhorias foram desenvolvidas de forma independente.

## Tecnologias

- React
- TypeScript
- Styled Components
- API REST
- Vite

## Funcionalidades

- Catálogo de produtos
- Carousel de destaques
- Consumo de API
- Interface responsiva
- Navegação entre seções

## Objetivos do Projeto

Este projeto foi desenvolvido para aprofundar conhecimentos em:

- React
- TypeScript
- Consumo de APIs
- Componentização
- Responsividade
- Boas práticas de desenvolvimento Front-End
